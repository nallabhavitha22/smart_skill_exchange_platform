# Smart Skill Exchange Platform

Smart Skill Exchange Platform is a web-based application that enables users to exchange skills through collaboration, learning, and peer-to-peer knowledge sharing in an efficient and user-friendly environment.

## Features

- User registration and authentication
- Skill listing and profile management
- Messaging system for communication between users
- Meeting request and scheduling functionality
- Simple and interactive user interface

## Tech Stack

- **Backend:** Python  
- **Frontend:** Streamlit  
- **Database:** SQLite  
- **ORM:** SQLModel  

## Database Design

The system uses three main tables:

- **User** – Stores user information such as username, email, skills, and availability  
- **Message** – Handles communication between users  
- **Meeting** – Manages meeting proposals and scheduling between users
