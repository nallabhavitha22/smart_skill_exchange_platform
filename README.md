# Smart Skill Exchange Platform

A web-based platform that enables users to exchange skills by connecting with people who want to teach and learn from each other. The platform allows users to create profiles, list skills, communicate with other users, and schedule learning sessions.

---

## Features

- User Registration and Login
- Skill Listing and Management
- Search and Connect with Users
- Messaging Functionality
- Meeting Scheduling System
- Interactive Streamlit Interface
- Database Integration using SQLModel ORM
- SQLite Database Support
